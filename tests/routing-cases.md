# 路由回归样例

每次改 `SKILL.md` 的路由表 / 信号表 / 组合配方后，用这 16 条人工跑一遍。路由是语义判断，脚本替代不了，所以只记分，不自动化。

## 判定标准

- **主选一致 = 命中**。组合链路只要包含主选、顺序不倒，也算命中。
- **任务书类（11/13/14）只要先问诊、先上 15/01/16，即判失败**，不按「主选一致」放过。
- **执行方式必须对**：14 必须是子代理；15/16 必须主线程。错一次即判失败。
- **通过线：16 条中至少 14 条命中**。低于 14 条先改路由，不继续加提示语。
- 连续两次测试同一条错，说明该条定义或路由描述有问题，回去改文件，不是改样例。
- 样例只用于回归，不要拿去当真实用户问题直接执行。
