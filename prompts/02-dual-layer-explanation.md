# 双层解释法

> 来源：卡兹克《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》· 场景二「学习」
> 解决的问题：这个概念我完全听不懂。

## 什么时候用

「把我当小学生解释」容易停在「好像懂了」——类比记住了，机制还是一团雾。小白版 + 专业版各讲一遍，才能真懂。

## Prompt

```
我想学习的是：【填写概念或问题】。

请分两层解释：

第一层，小白版。用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。

第二层，专业版。使用准确术语，讲清核心机制、适用边界和常见误解。

最后请整理出：1. 列出小白说法与专业术语的对应关系；2. 我最容易理解错的地方；3. 3个用于检查我是否真正理解的问题。
```

## 执行要点

- 两层必须都给，不要只写通俗版糊过去。
- 专业版要有适用边界和常见误解，不是术语堆砌。
- 结尾的 3 个检查问题是关键：让用户自测，不是复述。
