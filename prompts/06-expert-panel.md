# 专家会诊

> 来源：卡兹克《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》· 场景三「解决问题」
> 解决的问题：这个问题需要多个专业互相配合，单一视角不够。

## 什么时候用

替代「你是一位拥有20年经验的世界级专家」这种单角色开场。很多问题本质上需要多专业协作，而且**真正的信息往往在分歧里**。

## Prompt

```
我的问题是：【填写问题、已知事实、目标和现实约束】。

先不要直接给方案。请为这个问题选择3种真正互补的专业视角，并说明每种视角为什么必要。

让每种视角分别回答：1. 它怎样重新定义这个问题；2. 它最推荐的解决路径；3. 其他视角最容易忽略的风险；4. 什么新证据会让它改变判断。

然后让三种视角互相质疑，找出：1. 共同认可的事实；2. 真正的分歧；3. 分歧背后的不同假设。

最后请综合输出：1. 综合后最推荐的方案；2. 适用条件；3. 最大风险；4. 退出条件；5. 第一步行动。

不要选择三个高度相似的身份，也不要模仿或编造真实人物的观点。信息不足时，先只问我一个最关键的问题。
```

## 执行要点

- 三个视角必须**真正互补**。三个相似身份是本 Prompt 明确禁止的失败模式。
- 禁止模仿或编造真实人物的观点。
- **互相质疑那一步不能省**，它是整个 Prompt 的价值来源。
- 信息不足时只问一个最关键的问题，不要抛问卷。
- 结论必须带退出条件——什么情况下应该放弃这个方案。
