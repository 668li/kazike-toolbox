# 双向钢人论证

> 来源：卡兹克《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》· 场景四「决策」
> 解决的问题：两个答案都有道理，我到底该选哪一个。

## 什么时候用

已经有了答案候选、卡在选择上的时候。

与苏格拉底式提问的区别（作者亲自澄清）：苏格拉底式是帮你**更好地提出问题**；双向钢人论证是你**已经有答案之后做决策**用的。

## Prompt

```
我需要做的决定是：【写清问题、两个选项、目标和现实约束】。

先别急着回答，也别默认我已经把问题想清楚。请先做一次双向钢人论证：

1. 用最完整、有力的方式，重述我真正需要做出的选择；2. 分别给出支持两个方向的最强理由、适用条件、最大收益、最大风险，以及最难回答的反对意见；3. 找出双方真正的分歧、最可能改变结论的关键变量，以及还需要补充的信息；4. 只问我一个最可能改变结论的问题。

等我回答以后，再给出明确判断、理由、适用条件和下一步行动。
```

## 执行要点

- **钢人不是稻草人**：两个方向都要给最强版本的理由，不能一边强一边弱。
- 「最难回答的反对意见」两边都要写。
- 只问一个问题，等用户回答再下判断——不要跳过这一步直接推荐。
- 最终判断要明确（不要「取决于你」），但必须附带适用条件。
