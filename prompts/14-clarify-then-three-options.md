# 先对齐，再三案

> 来源：用户投稿（2026-11-19）· 原始表述：「先问一些不清晰的问题，对齐我的喜好，然后再出3版方案。」
> 解决的问题：方案不算差，但方向不是我想要的；或者所谓三版只是同一方案的三种包装。

## 什么时候用

你要的是方案、设计、文案、路线或产品形态，但需求里有一堆没说出口的偏好：预算、时间、审美、风险承受度、不能碰的边界。

## Prompt

```
我要解决的问题是：【填写要解决的问题、目标，以及已知的预算/时间/风险约束】。请先不要给方案。

先找出 3–5 个真正会改变方案方向、但我还没说清的问题。一次只问一个，等我回答后再问下一个。问题要具体到能改变取舍，不要问「你有什么偏好」这种空话。

问清之后，给我 3 版差异明显的方案：
A. 最稳版：风险最低，上限也最低；
B. 最优版：收益最大，代价也最高；
C. 反常版：跳出默认假设，可能失败，也可能打开一条新路。

每版写清：核心思路、适用前提、需要我付出的代价、最可能失败的地方、什么信号说明它不适合我。

最后说明你推荐哪一版、依据是什么；决定权在我。
```

## 执行要点

- **先问后答，不许边问边给方案**。问的时候一次一个，最多 5 个。
- 三版必须**真的不同**：不是同一方案的低配/中配/高配，也不是换皮。
- 偏好要落到**可核对的约束**：多少钱、多长时间、谁维护、最不能接受什么。
- 推荐要给依据，但**不替用户拍板**。
- 如果用户已经说清所有约束，跳过提问直接出三版，不要为了走流程硬问。
