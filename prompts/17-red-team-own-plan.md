# 最强反对者

> 来源：用户投稿（2026-11-19）· 原始表述：「先假设你当前认为最合理的方案是错误的。站在最强反对者的角度，寻找能够推翻它的证据、反例和边界情况。然后重新评估方案，看看有没有更好的解法。」
> 解决的问题：方案被自己的确认偏误保护着，没有人真正反对过它。

## 什么时候用

已经有一个「看起来最合理」的方案，需要一个足够强的对手把它打一遍。两个选项之间的取舍用 `09-bidirectional-steelman.md`；这条用于**单个方案的证伪**。

## Prompt

```
我目前认为最合理的方案是：【填写方案内容、它要解决的问题、你认为它成立的主要理由】。

请先假设它是错的。不是挑小毛病，而是站在最强反对者的立场——一个足够聪明、掌握同样事实、但结论完全相反的人——找出能推翻它的证据、反例和边界情况。

请回答：
1. 它在什么条件下必然失效？
2. 支持它的证据里，哪些是选择性取证、幸存者偏差或循环论证？
3. 最可能被忽略的反例是什么？
4. 如果它失败，最可能的失败路径是哪条？
5. 出现什么新信息时，我应该立刻放弃它？

然后用同样的标准重新评估：修正后的方案是否仍然成立？如果成立，最强版本是什么；如果不成立，有没有更好的解法？请直接给结论，不要为了平衡而各打五十大板。
```

## 执行要点

- 反对者必须是**最强版本**，能说服一个聪明人；写成稻草人等于没测。
- 必须给**放弃条件**：什么信号出现就停止投入。
- 重新评估要**真做**，不是走个过场然后维持原判。
- 结论明确：成立就写最强版本，不成立就写替代方案。
- 不要把「有风险」当成「不成立」；风险和证伪是两件事。
