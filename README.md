# 卡兹克工具箱 · kazike-toolbox

**21 条中文思考/决策提示词，做成一个可被 agent 稳定调用的 skill。**

不是又一个「提示词合集」：这个仓库的重点是**怎么让 agent 在正确的时候用、用对、用深**。

## 它解决什么问题

| 你输入 | 它会怎么做 |
|---|---|
| 完整任务书（对象 + 动作 + 交付物） | **不路由、不问诊**，直接执行对应 prompt；缺的上下文默认当前仓库/最近 30 天，并声明假设 |
| 「帮我选一条 / 该用哪条 / 用什么思路」 | 才读 `ROUTER.md`，按三维定位选 1–3 条 |
| 模糊请求 | 只问一个最关键的问题，不一次性甩问卷 |
| 单发型任务（审计、推演、核查、拆解） | 派子代理执行，主线程只做打包、派发、验收、转述 |
| 多轮型任务（问诊、决策、人生设计） | 留主线程，一次一问，等用户回答 |

## 结构

```text
SKILL.md           # 入口：输入分诊 + 索引 + 怎么答
ROUTER.md          # 显式路由：三问定位 + 信号表 + 组合配方（只在“帮我选”时读）
DELEGATION.md      # 子代理标准：谁执行 + 任务包模板 + 验收/转述边界
prompts/           # 21 条提示词原文
hooks/             # 可选：UserPromptSubmit + PreToolUse 路由闸门
tests/             # 16 条语义回归样例
verify.py          # 结构自检
```

## 快速开始

1. 把本目录放到：

```text
~/.agents/skills/kazike-toolbox
```

Windows 对应 `%USERPROFILE%\.agents\skills\kazike-toolbox`。

2. 可选：注册路由闸门 hook，见 [`hooks/README.md`](hooks/README.md)。不装也能用，装了模型就不能跳过 `ROUTER.md`。

3. 在 agent 里直接说：

```text
用卡兹克工具箱帮我选一条：我纠结 A 还是 B
```

或者直接给任务书：

```text
用卡兹克工具箱：假设明天有一个完全不了解项目、但能力很强的工程师接手，评估认知成本并给简化方案。
```

## 为什么不是同质化

12 条原文在网上已经有多份整理，单卖「12 条」没有差异。这个仓库的差异在**执行层**：

- **任务书直通**：完整任务书不路由、不问诊，避免「为了走流程先问你五个问题」。
- **显式路由**：只有你明确要选提示词时才读 `ROUTER.md`，避免自动路由把深度任务降级成问诊。
- **子代理分工**：单发条派子代理，主线程只做编排；多轮条留主线程。这是把「提示词」变成「可执行工作流」的关键。
- **Hook 强制**：路由层不靠模型自觉，消息触发时直接注入规则。
- **回归/自检**：16 条语义样例 + `verify.py`，改一处时至少知道还有几处要跟着改。
- **13–21 是增量**：需求诊断、二阶影响、红队、Git 考古、认知成本、PR 卡顿、复盘制度化，面向真实工程/决策，不是原文复刻。

如果你只想要 12 条提示词，网上有更轻的整理；如果你要的是「agent 真的按提示词干活」，再看这个。
